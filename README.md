# Planilha-de-investimento-conforme-perfil
Essa planilha é destinada a investidores iniciantes que desejam começar a investir. Aqui você consegue realizar projeções de investimento e acumulo de patrimônio conforme a quantidade de aporte realizado pelo investidor.
Utilidade do repositório:
1)As perguntas que a ferramenta responde, e onde aparece cada resposta;
Essa ferramenta auxilia os investidores avaliarem quanto é necessário investir para atingir uma meta, demonstrando as projeções conforme os aportes realizados.
2)Como o VF e o PROCV entram nos cálculos;
O VF é usado para estimar o valor total acumulado de patrimônio conforme o aporte realizado pelo investidor e a taxa de juros.
O PROC V mostra um resultado conforme as opções apresentadas em uma tabela de apoio para retornar um valor de acordo com o perfil do investidor. Pode ser usado para demonstrar o percentual ou valor aproximado dos aportes para cada tipo de investimento.
3)Os intervalos nomeados que você criou;
Os intervalos nomeados permite que evite erros ao selecionar as células para inserir nas fórmulas principalmente se o banco de dados for muito extenso garantindo organização mais clara e fácil na hora de utilizar.
4)Os percentuais de cada perfil, e de onde vieram;
Os percentuais de cada perfil são baseados no tipo de investimento mais comum para cada tipo de perfil apresentado no mercado de investimento.
5)O que você mudou em relação à ferramenta do Expert.
Não mudou nada, foi feita uma cópia exata.
